# 树及其自定义

如果你希望在左侧标签页中拥有超出标准树形结构的内容，可以在tree.js中实现。你可以更改树的布局，包括创建非图层节点、将其改为树以外的形式，或者完全隐藏左侧标签页。这里还引入了“树”组件，它也可以用于你的图层中。

## layoutInfo
最重要的部分是layoutInfo，包含：
- startTab：游戏开始时右侧默认显示的标签页ID。
- startNavTab：游戏开始时左侧默认显示的标签页ID。

- showTree：如果为true，则在游戏开始时显示树标签页。（另一个标签页将占据整个页面）
- treeLayout：如果存在，则覆盖树布局，并按照你的描述放置节点（在下一节中说明）。

此外，如果你希望主布局不是树形结构，你可以编辑tree.js底部的“tree-tab”图层，像修改普通图层的标签页一样修改它。你甚至可以使用showNavTab(layer)在左侧标签页之间切换，使该图层显示在左侧。

## 树

树组件定义为数组的数组，其中包含要在树中显示的图层或节点的名称。它们的工作方式与主树中的图层/节点相同（但如果存在重复项，节点之间的分支将仅作用于第一个节点）。

以下是一个树的示例：
```js
[["p"],
 ["left", "blank", "right", "blank"]
 ["a", "b", "blank", "c", "weirdButton"]]
```

## 节点

节点是可以放入树中的非图层按钮。它们的定义方式与图层类似，但使用addNode而不是addLayer。

特性：

- color：**可选**，节点的颜色。（十六进制格式的字符串，带#）

- symbol：**可选**，按钮上的文字（默认使用ID的首字母大写形式）

- canClick()：返回一个布尔值，表示玩家是否可以点击该节点。

- onClick()：点击节点时调用的函数。

- layerShown()：**可选**，返回布尔值的函数，决定该节点是否应可见。它也可以返回“ghost”，这将隐藏该图层，但其节点仍会在树中占据空间。

- branches：**可选**。图层/节点ID的数组。在树中，从该节点到列表中的所有节点将出现一条连线。或者，数组中的条目可以是包含ID和颜色值的2元素数组。颜色值可以是十六进制颜色代码的字符串，也可以是1-3的数字（受主题影响的颜色）。

- nodeStyle：**可选**。一个CSS对象，键为CSS属性，用于设置树上该节点的样式。

- tooltip() / tooltipLocked()：**可选**。返回文本的函数，分别用于图层解锁或锁定时节点的提示文本。默认情况下，提示行为与原始声望树相同。

- row：**可选**，该节点在默认树中出现的行。

- position：**可选**，决定图层在默认树中其行内的水平位置。默认情况下，使用ID，图层/节点按字母顺序排序。
