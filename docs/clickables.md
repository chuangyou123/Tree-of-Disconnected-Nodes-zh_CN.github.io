# 可点击项

可点击项是指任何你可以点击以产生效果的东西。它们是可购买项（Buyables）的更通用版本。

不要用这些来制作需要反复点击以获得奖励的东西，因为那种设计很糟糕。

两者之间有几个区别。其一，可购买项的存档数据是其数量（以`Decimal`表示），而可点击项存储的是“状态”，可以是数字或字符串，但不能是`Decimal`、数组或对象。可购买项有许多额外功能，你可以在其页面上查看。可点击项的默认尺寸也较小。

用于处理可点击项及实现其效果的有用函数：

- getClickableState(layer, id)：获取玩家拥有的可点击项的状态
- setClickableState(layer, id, state)：设置玩家拥有的可点击项的状态
- clickableEffect(layer, id)：返回该可点击项的当前效果（如果有）。

可点击项的格式应如下所示：

```js
clickables: {
    11: {
        display() {return "Blah"},
        etc
    }
    etc
}
```

功能特性：

- title：**可选**。显示在顶部，字体较大。也可以是一个返回更新文本的函数。
                    
- effect()：**可选**。一个计算并返回该可点击项当前加成值的函数。可以返回一个值或包含多个值的对象。

- display()：一个函数，返回在标题之后应显示在可点击项上的所有内容，通常会根据其状态而变化。可以使用基础HTML。

- unlocked()：**可选**。一个返回布尔值的函数，用于确定可点击项是否可见。默认为已解锁。

- canClick()：一个返回布尔值的函数，用于确定你是否可以点击该可点击项。

- onClick()：一个实现点击该可点击项功能的函数。

- onHold()：**可选**。当按钮被按住至少0.25秒时，每秒调用20次的函数。

- style：**可选**。以对象形式向该可点击项应用CSS，其中键为CSS属性，值为这些属性的值（均为字符串）。

- marked：**可选**。在可点击项角落添加标记。如果为“true”则显示星形，但也可以是图片URL。

- tooltip：**可选**。为该可点击项添加悬停提示，当鼠标悬停时显示。可以使用基础HTML。默认为无提示。如果此函数返回空值，也会禁用提示。

- layer：**自动分配**。与该层名称相同，因此你可以使用`player[this.layer].points`或类似操作。

- id：**自动分配**。即该可点击项存储时所用的“键”，便于访问。示例中可点击项的id为11。

你还可以在可点击项对象上使用以下功能，在所有可点击项上方添加一个按钮，用于实现重置技能按钮或类似功能。

- masterButtonPress()：**可选**。如果存在，将在可点击项上方显示一个额外按钮。按下该按钮将调用此函数。

- masterButtonText：**可选**。在主按钮上显示的文本。

- showMasterButton()：**可选**。一个函数，用于确定是否显示该按钮（如果已定义masterButtonPress）。若缺失则默认为true。

- branches：**可选**，主要用于可点击项树。一个可点击项id数组。从该可点击项到列表中的所有可点击项之间将出现一条连线。或者，数组中的条目可以是一个由可点击项id和颜色值组成的2元素数组。颜色值可以是包含十六进制颜色代码的字符串，也可以是1-3的数字（受主题影响的颜色）。数组中的第三个元素可选地指定线宽。
